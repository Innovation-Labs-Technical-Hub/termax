# app-shell-design-system Specification

## Purpose

Specifies Termax's desktop application shell (left rail, tabs/workspaces, multi-window, command palette, keymap, status bar, toasts/notifications, error banners with OXT codes) and its design system (tokens, themes, contrast, zoom, reduced motion, AccessKit accessibility, VI/EN i18n with Fluent, searchable settings, onboarding). Every screen in BRD-02…BRD-08 is built on the shell and tokens defined here.

Source: BRD-01 “App shell, navigation, design system & settings” v1.0 (draft) (2026-10-30). Modules: UI-01, UI-10. Generated by `tools/openspec_from_brd.py`; edit through OpenSpec changes.

## Requirements

### Requirement: FR-UI01-001 Persistent 8 + 3-item left rail
The system SHALL provide: Persistent 8 + 3-item left rail.

Source: BRD-01 FR-UI01-001 · Module: UI-01 · Priority: Must · Phase: P1  
VI: Left rail cố định 8 + 3 mục

#### Scenario: FR-UI01-001 specified behaviour

### Requirement: FR-UI01-008 Shortcut conflict detection
The system SHALL provide: Shortcut conflict detection.

Source: BRD-01 FR-UI01-008 · Module: UI-01 · Priority: Must · Phase: P1  
VI: Phát hiện xung đột phím tắt

#### Scenario: FR-UI01-008 specified behaviour
- **GIVEN** the system implements FR-UI01-008
- **THEN** When recording a chord or importing a keymap, the system detects: (a) the same chord bound to two actions in overlapping contexts; (b) OS-reserved chords (Cmd+Q, Alt+F4, Win+L, IME/keyboard-layout switch keys); (c) chords that would stop the shell receiving keys in a terminal (Ctrl+C, Ctrl+W, Ctrl+R, Ctrl+D on Windows/Linux); (d) collisions produced by the Mod = Ctrl+Shift rule inside terminals (e.g. Mod+T and Mod+Shift+T both becoming Ctrl+Shift+T). #### Scenario: FR-UI01-008 acceptance 1
- **GIVEN** “Close pane” is bound to Mod+W
- **WHEN** the user assigns Mod+W to “Open SFTP” in the same context
- **THEN** a conflict dialog names “Close pane” and offers Replace / Choose another / Cancel, and nothing is saved until the user chooses

#### Scenario: FR-UI01-008 acceptance 2
- **GIVEN** Windows with a focused terminal
- **WHEN** the user binds Ctrl+R (without Shift) to an app action
- **THEN** a warning says the shell will no longer receive Ctrl+R (reverse search) and explicit confirmation is required

#### Scenario: FR-UI01-008 acceptance 3
- **GIVEN** the default keymap of each of the 3 OSes
- **WHEN** the CI keymap test runs
- **THEN** it reports 0 conflicts, including collisions from expanding Mod to Ctrl+Shift

## Business rules

- **BR-01-01**: Every user-facing action must be registered in the command registry with a stable action id, VI + EN title, keywords, context and optional default chord; actions missing from the registry may not ship.
- **BR-01-02**: Errors are shown non-modally within the affected scope; modal UI is reserved for security decisions (host-key trust) and irreversible actions; the chrome never beeps.
- **BR-01-03**: Colour is never the only carrier of meaning: environment, connection state, PQ and contrast warnings always come with text or an icon.
- **BR-01-04**: Mod = Cmd on macOS; on Windows/Linux Mod = Ctrl outside terminals and Ctrl+Shift inside a focused terminal so plain Ctrl chords reach the shell; any binding that captures a plain Ctrl chord in a terminal needs explicit user consent.
- **BR-01-05**: OXT code ranges: 1xxx network/connection, 2xxx authentication & trust, 3xxx file transfer, 4xxx vault/keys, 5xxx agent/MCP/policy, 6xxx account/sync/billing, 7xxx import/export, 8xxx platform/update/plugins, 9xxx internal. Released codes are never reused or renumbered; deprecated codes stay documented.
- **BR-01-06**: Telemetry and crash reporting stay off until the user opts in; onboarding never pre-ticks consent.
- **BR-01-07**: The chrome never uses PuTTY or Termius names/logos; icons come only from Lucide (ISC), never emoji.

## User journeys

### J-01-01 First run to first connection within 60 seconds
1. Open the app for the first time; onboarding appears in Vietnamese from the OS locale with Dark preselected.
2. Skip import or jump to the import wizard (BRD-02).
3. Privacy step: telemetry and crash reports stay off.
4. Press Mod+K, type `ubuntu@192.168.1.20`, press Enter; a new tab opens and connects.
5. A “Save as host” toast appears; the user saves it with one key.

### J-01-02 A keyboard user remaps a shortcut and resolves a conflict
1. Mod+, opens Settings; type “keymap” to reach Keyboard.
2. Select “Split down” and press the new chord Ctrl+Shift+W on Linux.
3. The conflict dialog reports a clash with “Close pane” in the terminal context; choose Replace.
4. Palette, menus and tooltips show the new chord at once; export the keymap to TOML.

### J-01-03 Recovering from a connection error through a coded banner
1. Connecting to a host is refused on port 22.
2. The pane shows a “Connection refused” banner with code TMX-1003, with no modal box or beep.
3. The user picks Edit host, changes the port to 2222 in the side sheet, then Retry.
4. If it still fails, they pick Ask AI or Copy details for support.

### J-01-04 A low-vision user sets up high contrast, zoom and a screen reader
1. Turn on Windows High Contrast; Termax switches to system colours immediately.
2. Settings › Accessibility: UI zoom 175 %, reduced motion on.
3. Use F6 to jump between rail, tabs, canvas and status bar; Narrator reads each item's name and state.
4. The checker reports the terminal theme at ≥7:1.

## Data entities

- **settings**: key, scope(app), value_json, schema_version, updated_at, device_id — App layer of inheritance; host/group/vault overrides live in host_settings (BRD-02).
- **settings_history**: id, key, old_value_json, new_value_json, changed_at — Last 100 changes for Undo/revert.
- **keymaps**: id, name, base_preset(default|terminal_first), created_at, updated_at — User keymaps; built-in presets are not stored in the DB.
- **keybindings**: id, keymap_id, action_id, chord, context(global|terminal|palette|sftp|sheet), os(all|mac|win|linux), source(default|user) — Each row is one chord for one action in one context.
- **workspaces**: id, name, layout_json(windows→tabs→split tree→host/session refs), restore_policy(focused_only|all|none), last_opened_at — Holds no secrets or scrollback.
- **windows**: id, workspace_id, bounds, monitor_id, scale, maximised, rail_collapsed — Restores position and DPI for multi-window.
- **notifications**: id, level(info|warn|error|success), code, message_id, args_json, actions_json, session_id, read_at, created_at — Keeps the last 200; args are redacted.
- **themes**: id, kind(ui|terminal), name, tokens_json, source(builtin|import|user), contrast_report_json, updated_at — Built-in UI themes are read-only; terminal themes are editable.
- **error_catalog**: code(TMX-NNNN), severity, message_id, doc_anchor, default_actions, since_version, deprecated_in — Shipped with the app as data; source of truth for NFR-01-009.
- **onboarding_state**: version, completed_at, skipped_steps, import_offered — Allows re-showing onboarding for a new version.

## Interfaces

- **IF-01-01 CommandRegistry (termax-ui)** (Rust API): register(action_id, title_msg, keywords, context, default_chords, handler, enabled_when); query(scope, text) returns ranked results for the palette, menus and tooltips.
- **IF-01-02 KeymapService (termax-ui)** (Rust API): resolve(chord, context) → action; detect_conflicts(keymap, os) → conflicts (duplicate, OS-reserved, shell-blocking, Mod→Ctrl+Shift); TOML import/export.
- **IF-01-03 NotificationService (termax-ui + termax-platform)** (Rust API): post(level, code, message_id, args, actions, scope) → toast, notification centre and native notification when unfocused; rate-limited for bells.
- **IF-01-04 ErrorCatalog (termax-core)** (Rust API / data file): Maps internal error enums to OXT codes; lookup(code) → Fluent message ids, doc anchor, default actions.
- **IF-01-05 DeepLinkRouter (termax-platform)** (URL scheme): Handles termax://settings/<section>/<id> and termax://action/<id>; shares the router with BRD-02 host links (FR-CO11-010).
- **IF-01-06 ThemeProvider (termax-ui)** (Rust API): Serves tokens per theme, listens to OS appearance/high contrast, exposes contrast(fg, bg) for the checker and minimum-contrast enforcement.
- **IF-01-07 I18n (Fluent bundles vi/en/pseudo)** (Rust API): format(message_id, args), locale-change event, locale-aware number/date/size formatting.
- **IF-01-08 tmx settings open <id>** (CLI (PL-04)): Opens the app at a setting through the local control endpoint.
