# terminal-workspace Specification

## Purpose

Define the business, functional and non-functional requirements for the three blocks that make up the Termax terminal experience: (1) the terminal workspace (tabs, splits, layouts, broadcast, find bar, paste guard, selection, links, disconnect overlay, auth prompts outside the grid); (2) the TermCore terminal core (budgeted parser on its own task, SSH window credit, Frame/Damage, tiered scrollback, indexed search, policy-gated OSC, modern keyboard/mouse, Unicode 16); (3) the GPU renderer (glyph atlas, vsync presentation, damage-only drawing, hidden-tab skipping). The goal is the ARCH-BRIEF §6 targets (key→photon ≤1 frame, parser ≥300 MB/s, ≤3 MB RAM per tab, zero render for hidden tabs) while keeping PuTTY's safety DNA: paste filtering, trust-sigil anti-spoofing and bell-flood protection.

Source: BRD-03 “Terminal workspace, terminal core & renderer” v1.0 (draft) (2026-10-30). Modules: UI-04, CO-04, CO-05. Generated by `tools/openspec_from_brd.py`; edit through OpenSpec changes.

### Requirement: FR-UI04-001 Tab strip and multi-window workspace
The system SHALL provide: Tab strip and multi-window workspace.

Source: BRD-03 FR-UI04-001 · Module: UI-04 · Priority: Must · Phase: P1  
VI: Thanh tab và workspace nhiều cửa sổ

#### Scenario: FR-UI04-001 specified behaviour
- **GIVEN** the system implements FR-UI04-001
- **THEN** All sessions run in one process with multiple windows. A tab shows the host name, an environment colour that always carries a text label (PROD/STAGING/DEV), and a status dot with a text badge (Connected, Reconnecting, Disconnected, Bell, Activity). #### Scenario: FR-UI04-001 acceptance 1
- **GIVEN** 3 open tabs
- **WHEN** the third tab is dragged out of the window
- **THEN** a new window holding that session is created, the session does not reconnect and its scrollback is intact

#### Scenario: FR-UI04-001 acceptance 2
- **GIVEN** a pane running a command (OSC 133 has not reported completion)
- **WHEN** Mod+W is pressed
- **THEN** a confirmation names the command; choosing Cancel keeps the pane

#### Scenario: FR-UI04-001 acceptance 3
- **GIVEN** a host tagged prod
- **THEN** its tab shows #F87171 together with the text label ‘PROD’ (never colour alone)

### Requirement: FR-CO04-002 Parser task, SPSC ring and window credit (H1)

## Business rules

- **BR-03-01**: Auth prompts, host-key decisions and any Termax-generated message appear only in native chrome or in a gutter with a trust sigil; server output can never render something that looks like Termax chrome.
- **BR-03-02**: Paste control-character filtering is always on (keeping CR, LF, TAB, BS); it can only be turned off per host under Advanced, and the tab then shows a warning badge.
- **BR-03-03**: OSC 52 clipboard reads are never allowed; OSC 52 writes default to ‘ask’ per host, and prod-tagged hosts default to ‘deny’.
- **BR-03-04**: Remote window operations (move, resize, iconify, raise/lower) are always ignored; title reports return empty; answerback defaults to empty.
- **BR-03-05**: Broadcast is always visibly indicated on every receiving pane; prod-tagged hosts join only after an explicit per-broadcast confirmation.
- **BR-03-06**: Hidden, occluded or minimized panes render nothing; the model keeps updating so it can be shown at once when visible again.
- **BR-03-07**: The parser never pauses because of the UI (selection, scrolling, dragging); backpressure flows only through SSH window / read credit.
- **BR-03-08**: Scrollback lives only in memory and is never written to disk in plaintext; logging is a separate CO-12 function with secret redaction.
- **BR-03-09**: Links open only after an explicit user gesture (Mod+click or a URL hint); schemes other than http/https require confirmation.

## User journeys

### J-03-01 Investigating a prod incident while logs stream
1. Open host api-prod (tab labelled ‘PROD’), press Mod+D to split and run `journalctl -f` in the right pane.
2. Scroll up to read earlier errors; the viewport stays put and a ‘320 new lines ↓’ badge counts new lines.
3. Press Mod+F, enable regex, search `ERROR|timeout`; the first hit is highlighted almost instantly.
4. Double-click the trace URL to select it whole, Mod+click to open it in the browser; Alt+drag to copy a column block.
5. Click the badge to jump back to the bottom and keep following.

### J-03-02 Safely pasting a multi-line script into a prod host
1. Copy a 12-line snippet containing `sudo systemctl restart` from a wiki.
2. Right-click in the pane: the context menu opens and nothing is sent; choose Paste.
3. The paste guard shows a ‘12 lines’ preview, flags `sudo` and shows which control characters were removed.
4. Choose Paste; because the shell has bracketed paste on, the block is wrapped in 200~/201~ and does not auto-run.
5. Realising it is the wrong host, press any key: the rest is cancelled and the pane reports the bytes sent.

### J-03-03 Network drop and reconnect without losing context
1. Wi-Fi drops; the pane shows a ‘Disconnected · TMX-NET-004 Connection reset’ overlay and the tab gets a badge.
2. Scrollback stays readable, searchable and selectable under the overlay.
3. Auto-reconnect counts down per the backoff; the user presses Enter to retry now.
4. The server asks for an OTP: the OTP sheet appears in chrome under the pane header, labelled ‘From server’.
5. Once back in, a ‘— Reconnected 10:42 —’ line with a trust sigil is inserted in the gutter.

### J-03-04 Broadcasting a command to 5 web servers
1. Select 5 hosts tagged web on the Hosts page and choose ‘Open as broadcast group’.
2. 5 panes open in one tab; a host tagged prod asks for its own confirmation before joining.
3. A ‘Broadcasting to 5 panes’ banner and a coloured border show on every receiving pane.
4. Type `sudo nginx -t`; each pane gets the bytes for its own keyboard mode; a paste shows the paste guard once listing all 5 targets.
5. Press Stop on the banner to leave broadcast.
