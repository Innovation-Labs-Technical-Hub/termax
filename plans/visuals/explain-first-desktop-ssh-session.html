Open a saved host and use its shell

One window takes you from your existing encrypted vault to a remote shell. The example assumes a direct connection using a saved SSH key.

OxTerm · example-dev
dev@example-dev:~$ hostname
example-dev
dev@example-dev:~$ stty size
24 80
dev@example-dev:~$ exit
Session ended · Exit status 0

From saved host to shell

  1. Unlock the vault and choose an existing saved host.
  2. Verify the server key. For a new key, OxTerm shows its fingerprint outside the terminal grid.
  3. Use the remote shell, resize the window, then type exit. OxTerm shows the exit status and lets you return to Hosts.

If the connection fails

The server key changed

OxTerm stops before authentication and shows the mismatch outside the terminal grid.

The network dropped

OxTerm shows the disconnect and lets you return to Hosts.

Terms

The vault stores saved hosts and trusted server keys. A remote PTY is the terminal interface the SSH server allocates for the shell.
